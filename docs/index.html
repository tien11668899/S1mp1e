把 Apple 的液態玻璃放進 Minecraft。啟動器和遊戲內介面一起換，1.8.9 到 26.2 都能玩。

遊戲裡，每一層都是玻璃

標題畫面、設定面板、背包、tooltip、聊天和名牌，全部換成會折射的玻璃，後面的世界看得到。

真的會折射

折射集中在邊緣，往內照這條曲線衰減到零。拖著玻璃走一圈，數值也能直接調。

r(d) = S · max(1 − d/D, 0)p
拖曳玻璃

新功能

戰鬥三件套

攻擊冷卻環、命中標記、火焰降低。只改畫面，不碰任何判定。

攻擊冷卻玻璃環

蓄力時沿著玻璃軌道填滿，蓄滿對準生物就換形狀。圓形、方框，或直接包住準星。

1.8.9 沒有攻擊冷卻，所以這一項只在 1.12.2 以後的版本。

準星分開，玻璃也分開

包覆會照你的準星大小、間隙、粗細和旋轉。間隙夠大，玻璃就分成四段各自包住。拉拉看。

命中標記

打中時準星旁彈出四段玻璃刻度，暴擊變橘色，擊殺變紅色。

可以只顯示暴擊，也能換成十字形、調大小和間距。

火焰畫面降低

著火時火焰往下移、變淡，還是看得出在燒，但不會擋住視線。也可以整個隱藏。

21 個模組，Right Shift 就能調

在遊戲裡的玻璃設定面板開關、調數值，HUD 的位置直接拖。

HUD

裝備欄藥水欄座標顯示 幀率顯示背包預覽按鍵顯示 隱藏飽食度彩虹 HUD

畫面

準星方塊外框全亮 手部位置固定視野經驗條流動 視野縮放

戰鬥

攻擊冷卻玻璃環命中標記火焰畫面降低 點擊速度關閉受傷晃動舊版動畫

啟動器
